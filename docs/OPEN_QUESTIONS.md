# Perguntas em Aberto

## CHECKPOINT 0 — Viabilidade, intenção e ambiente (bloqueante para código)

1. **CP0-1 · Finalidade do produto**
   - A) Uso exclusivo de uma empresa (interno)
   - B) MDM comercial/SaaS vendido a clientes externos
   - C) Projeto de aprendizado/portfólio com visão comercial futura — começa 100% no simulador ⭐ recomendado
2. **CP0-2 · Propriedade dos aparelhos**
   - A) 100% corporativos (Fully Managed + Dedicated/quiosque) ⭐
   - B) Mistos (corporativos + COPE)
   - C) Inclui BYOD (perfil de trabalho em aparelho pessoal)
3. **CP0-3 · Fabricantes e versões**
   - A) Samsung + Motorola, Android 12+ ⭐
   - B) Samsung prioritário (preparar Knox/OEMConfig depois)
   - C) Qualquer GMS, Android 10+
   - D) Inclui aparelhos sem GMS (PDV/coletores AOSP)
4. **CP0-4 · Frota**: nº de aparelhos inicial e em 2–3 anos (ex.: “50 → 2.000”).
5. **CP0-5 · Ambiente**: SO do computador, RAM, Docker, Git, VS Code, Android Studio, aparelho de teste que pode ser resetado de fábrica?
6. **CP0-6 · Orçamento/hospedagem**
   - A) R$ 0 — tudo local por enquanto ⭐
   - B) Até ~R$ 100/mês em cloud
   - C) Orçamento empresarial
   - Preferência: cloud / on-premise / indiferente
7. **CP0-7 · MDM e APIs existentes**
   - A) Nenhum ⭐ (modo simulador)
   - B) Empresa já usa um MDM (qual?) com API licenciada
   - C) Já tenho projeto Google Cloud / acesso AMAPI aprovado
